# FloorSight — dealer risk intelligence (demo)

Access-controlled sales materials for FloorSight, a dealer trust-score /
risk-management product for banks that provide floorplan financing to car dealers.

- **[Pitch deck](https://fleetbitapp.github.io/floorsight/)**
- **[Console demo](https://fleetbitapp.github.io/floorsight/console.html)**

Both pages are AES-256-GCM encrypted at rest and require an access code to view.
All dealers, figures and events in the demo are fictional.
